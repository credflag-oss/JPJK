# ✨ 나의 성장 캐릭터 테스트 (JPJK)

애니메이션 캐릭터 아키타입으로 발견하는 나의 성장 유형 테스트

🔗 **라이브**: https://credflag-oss.github.io/JPJK/

---

## 📋 개요

MBTI의 선호 경향, Big 5 성격 축, Grit의 끈기·몰입 특성을 참고해 구성된 성장 유형 테스트입니다.  
설문과 행동 반응을 함께 분석해 **생각하는 나**와 **실제로 반응하는 나**를 비교하고,  
가장 닮은 성장 캐릭터 유형(32가지)으로 결과를 보여줍니다.

---

## 🎮 테스트 구조 (4단계, 약 12~15분)

| 단계 | 내용 | 시간 |
|------|------|------|
| **1. 집중 반응 측정** | 두더지 잡기 or 색상 스트룹 테스트 | 30초 |
| **2. 성향 설문** | 8개 선택형 질문 | 약 2분 |
| **3. 우선순위 선택** | 압박 상황에서 8가지 카드 우선순위 결정 | 30초 |
| **4. 2주 여행 시뮬레이션** | 여행 중 8가지 상황 선택 | 약 5분 |

---

## 🐹 게임1: 집중 반응 측정

### 두더지 잡기
- 3×3 그리드에서 랜덤 등장하는 두더지(🐹)를 클릭
- 0.6~1.0초 랜덤 체류 시간
- 15초 이후 동시 2마리 등장 (난이도 상승)
- 순발력·시각 집중력 측정

### 색상 스트룹 테스트
- "빨강"이라는 글자가 파란색으로 표시되는 인지 간섭 효과
- **글자 내용이 아닌 글자의 색상**을 선택해야 함
- 일치(40%) / 불일치(60%) 혼합 출제
- 인지 유연성·처리 속도 측정

## 📊 결과 유형

**32가지 핵심 유형** (5개 축 × 2가지 = 2⁵)

| 축 | 구분 |
|----|------|
| 구조 | 구조형(S) / 유연형(F) |
| 시작 | 준비형(P) / 점화형(I) |
| 동기 | 성과형(O) / 성장형(G) |
| 집중 | 안정형(A) / 탐험형(X) |
| 압박 | 보호형(C) / 가속형(T) |

예시: `SPOAC` → 구조-준비-성과-안정-보호형 → **리바이 아커만 (진격의 거인)**
